# PUBG Ruler

**Tactical Distance Measurement Tool for PUBG**

PUBG Ruler is a Windows desktop overlay designed to help PUBG players measure distances on maps, calibrate map scale, and view secret locations.

## Features

- **Distance Measurement** — measure distances between two points (A → B).
- **Map Calibration** — calibrate map scale using known reference distances.
- **Customizable Hotkeys** — assign your preferred keys to measurement actions.
- **Secret Location Maps** — view maps with marked secret locations for Erangel, Rondo, Miramar, Taego, and Paramo.
- **Windows System Tray** — minimize the application to the system tray.
- **Always-on-Top Mode** — keep the tool visible above other windows.
- **Tactical Interface** — dark design with red accents, inspired by PUBG.
- **Built-in Maps** — map images are embedded in the application, so no separate map folder is required.

## How to Use

### 1. Download and Launch

Download `PUBG_Ruler.exe` from the [Releases](../../releases/latest) section and run it.

### 2. Calibrate the Map

1. Select **Reference 1** or **Reference 2**.
2. Draw a line over a distance on the map that you know.
3. Enter the real distance in meters.
4. The application uses this reference to calculate the map scale.

For better accuracy, you can set two reference distances.

### 3. Measure Distance (A → B)

1. Start the A → B measurement using its button or assigned hotkey.
2. Mark point A and point B on the map by drawing a line.
3. View the calculated distance in meters.
4. Stop the measurement when finished.

### 4. Secret Locations

1. Open **Secret Locations**.
2. Select a map from the list.
3. View the map image with marked secret locations.

Available maps: Erangel, Rondo, Miramar, Taego, and Paramo. More maps may be added in future versions.

### 5. Hotkeys and System Tray

- Open **Settings** to change the hotkeys.
- Use the system tray icon to access the application when its main window is hidden.
- Enable **Always on Top** to keep the window above other windows.

Download the latest version from [GitHub Releases](../../releases/latest).

# PUBG Ruler — Русская версия

**Тактический инструмент для измерения расстояний в PUBG**

PUBG Ruler — это экранный виджет для Windows, который помогает измерять расстояния на картах PUBG, калибровать масштаб и просматривать секретные локации.

## Возможности

- **Измерение расстояний** — измеряй расстояние между двумя точками (A → B).
- **Калибровка карты** — настраивай масштаб по известным расстояниям.
- **Настраиваемые горячие клавиши** — назначай удобные клавиши для действий.
- **Карты секретных локаций** — просматривай карты с отмеченными секретными локациями на Эрангеле, Рондо, Мирамаре, Таэго и Парамо.
- **Системный трей Windows** — сворачивай программу в область уведомлений.
- **Поверх всех окон** — оставляй виджет поверх других окон.
- **Тактический интерфейс** — тёмный дизайн с красными акцентами в стиле PUBG.
- **Встроенные карты** — изображения карт находятся внутри приложения, отдельная папка с картами не требуется.

## Как пользоваться

### 1. Скачивание и запуск

Скачай `PUBG_Ruler.exe` из раздела [Releases](../../releases/latest) и запусти его.

### 2. Калибровка карты

1. Выбери **Эталон 1** или **Эталон 2**.
2. Проведи линию по участку карты, расстояние которого тебе известно.
3. Введи реальное расстояние в метрах.
4. Программа использует эталон для расчёта масштаба карты.

Для повышения точности можно задать два эталонных расстояния.

### 3. Измерение расстояния (A → B)

1. Запусти измерение A → B кнопкой или назначенной горячей клавишей.
2. Проведи линию от точки A до точки B на карте.
3. Посмотри рассчитанное расстояние в метрах.
4. Останови измерение после завершения.

### 4. Секретные локации

1. Открой раздел **Секретные локации**.
2. Выбери карту из списка.
3. Просмотри изображение с отмеченными секретными локациями.

Доступные карты: Эрангель, Рондо, Мирамар, Таэго и Парамо. В будущих версиях список может пополниться.

### 5. Горячие клавиши и системный трей

- Открой **Настройки**, чтобы изменить горячие клавиши.
- Используй значок в системном трее, чтобы открыть программу, когда её главное окно скрыто.
- Включи режим **Поверх всех окон**, чтобы окно оставалось над другими окнами.
